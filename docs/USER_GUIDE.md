## 日本語文書をコンパイルする

新規プロジェクトは通常 pdfLaTeX です。プロジェクトの Menu → Settings → Compiler で **LuaLaTeX** を選び、次の `main.tex` をコンパイルします。

```tex
\documentclass[lualatex,ja=standard]{bxjsarticle}
\usepackage{luatexja}
\title{日本語文書のテスト}
\begin{document}
\maketitle
日本語の本文をコンパイルします。
\end{document}
```

日本語本文には LuaLaTeX と `bxjsarticle` / `jlreq` 系クラスを使えます。英語中心の既存テンプレートも利用できます。移行時はテンプレートに合わせたコンパイラーとメイン文書の設定も確認します。[サンプル文書](samples)もあります。

## 翻訳する

1. `.tex` ファイルをソースエディタで開き、左のセクション（ファイルツリーや検索の並ぶ列）の **「英語翻訳」** タブを開きます。
2. 翻訳対象を「現在の .tex ファイル」または「選択範囲」から選びます。
3. 接続先は既定では「翻訳サービスの標準設定に従う」です。自分の LLM（BYO）で翻訳したい場合は **「LLM 設定で変更」** リンクの設定画面（ユーザー設定の LLM 項目）にある「英語翻訳の接続設定」で、保存済みの LLM 行・モデル・ミニマルプロンプト・チャンク字数を選びます。
4. 「用語集・文書コンテキスト・システムプロンプト」で必要な設定を保存します。
5. 設定した LLM に原文・用語集などを送る確認欄を選び、「確認して翻訳」を押します。
6. 原文と英訳を確認し、保存または適用します。

全文翻訳の「英語版 .tex として保存」は、同じフォルダーに `main.en.tex` のようなファイルを作り、原文を保持します。既に英語版がある場合は上書きを確認します。「保存して英語版をメイン文書に設定」は保存後にコンパイル対象とエディタタブも切り替えます。選択範囲の「選択範囲を原文に適用」は原文を変更するため、確認ダイアログを表示します。

翻訳中に元文書を編集すると、古い内容での上書きを防ぐため保存・適用を無効にします。共同編集者の操作も含むため、現在の内容で翻訳し直してください。

## 用語・文脈・プロンプト

- 用語集はプロジェクト単位で最大200項目。例: `信頼境界 → trust boundary`。
- 文書コンテキストには概要・統一したい文体などを最大4,000文字で指定します。
- システムプロンプトで翻訳の役割・スタイルを変更できます。空欄または「デフォルトに戻す」で既定文に戻ります。LaTeX 保護の検証用指示はサービスが常に付加します。
- 翻訳サービスはプロジェクトごとの直近3件の短い原文・訳文抜粋（各末尾700文字まで）を保存し、次の翻訳に使います。長文翻訳では前のチャンクの英訳も参照します。

翻訳の接続先はユーザーごとの LLM 設定画面で選びます。「標準設定に従う」を選んだ場合は翻訳サービス側の設定（保存済みエンドポイント → `.env` の `LOCAL_LLM_BASE_URL`）が使われます。[設定の優先順位](CONFIGURATION.md)も参照してください。

## 停止・失敗・部分結果

生成中は処理段階と暫定訳が表示されます。「翻訳を停止」は中継・LLM へのキャンセルを伝えます。暫定表示と検証済みの確定部分は別に扱われます。

LaTeX コマンド、数式、参照・引用、コメント、URL、波括弧などをマーカーで保護し、応答を検証します。失敗したチャンクは分割などで最大3回再試行し、それでも失敗すると該当部分を原文に戻して処理を続けます。完了時に失敗箇所が通知された結果には日本語が残るため、必ず確認してください。文書全体の検証でも修復できなかった結果は適用できません。

停止・通信エラーなどで未完了になっても、確定済みチャンクがあれば「訳済み部分をコピー」や「訳済み部分だけ英語版 .tex に保存（草稿）」を使えます。草稿は全文翻訳の完成版ではなく、末尾が欠けて LaTeX としてコンパイルできない場合があります。

## 日本語版・英語版の PDF を切り替える

各ファイルを右クリックして「メイン文書に設定」するか、翻訳保存時の切り替えを使います。各版で一度コンパイルしてください。成功した PDF とログは編集セッション内にメイン文書ごと最大4件保持され、コンパイル済みの版のタブに戻ると復元されます。

編集後の PDF は古い内容です。必要な版を再コンパイルしてください。ブラウザーの再読み込みや PC 移行ではこの一時キャッシュを引き継がないため、各版を再コンパイルします。

## 日本語と英語のソースを横並びで見る

翻訳パネルで英語版 `.en.tex` を保存すると、画面右端に **「横並び: 日本語 ⇄ 英語」** パネルが自動で開き、保存した英語版が表示されます。メインエディターの左が日本語原文、右のパネルが英語版で、見比べながら編集できます。

- 手動で開く場合は、左のセクションの **「横並び表示」** タブから .tex を選ぶか、「開いているファイルを横並びに」を押します。ここから閉じることもできます。
- パネルはタブ編集環境です。複数の `.tex` をタブで同時保持して切り替えられ、公式と同じツールバー（太字・イタリック等の書式ボタン）と検索、自動保存（約1.5秒）と Ctrl+S 保存が動きます。タブの × で閉じます。
- メインタブバーからファイルをドラッグ＆ドロップで右パネルへ移す、タブの「左へ戻す」ボタンでメインエディターへ返す、といった移動もできます。
- 編集して「保存」（または Ctrl+S）すると、Overleaf 本体の通常編集経路で保存されるため履歴・共同編集同期も正しく動きます。
- 同じファイルをメインエディターでも開いている間は、二重編集を防ぐため横並びパネルは読み取り専用になります（メイン側でタブを閉じれば編集できます）。

## AI に相談する（チャット）

左のセクションの **「AI Assistant」** タブ（llm モジュールのチャットレール）から、クラウド版 Overleaf と同じ形でローカル LLM に相談できます（内容は外部へ送信されません）。

- 質問・英語添削・LaTeX スニペット作成などを日本語で聞けます。
- **プロジェクトの TeX を自動参照**します（VS Code Copilot のような形・2026-11-13）。質問を送るとサーバー側が**質問文の意図を自動判定**して参照範囲を決め、回答の下に「参照: main.tex, …」と使用ファイルを表示します。
  - 「**全体・校正・表記ゆれ・一貫性**」など全体チェック系の質問 → プロジェクト全体の全文を添付（既定 60,000 字予算、超過ファイルは「省略」と明示）。
  - 質問に**ファイル名**（例: `methods.tex`、`refs.bib`）や**セクション名**（例: 「考察」「method」「はじめに」）が出ている → そのファイル・見出し付近を重点的に広め窓で収録。
  - それ以外 → 編集中のファイルの冒頭＋質問に合う箇所の抜粋（既定 12,000 字予算）。
  - 細かい挙動を変えたくない場合は LLM 設定画面でモードを「**常に全体を読み込む**」（質問にかかわらず毎回全文）や「**参照しない**」に固定もできます。**参照コンテキスト長（文字数）**も同じ画面で設定できます（空欄で既定。plamo 系の上限は入出力計 32,768 トークンなので、全体読み込みは原稿サイズに合わせて調整します）。Ask AI は選択範囲を添えるため対象外です。
- 入力の確定は **Enter** です。日本語変換中の Enter は変換確定だけで送信されません（改行は Shift+Enter）。Ask AI の入力欄も同じ挙動です。
- 機能別に使う AI を選べます。設定画面（`/user/llm-settings`）の「AI 機能ごとのモデル選択」で、AI Assistant チャット・Ask AI・インライン補完・文書生成・コンパイル修正・準拠レビューそれぞれのモデルを指定します。未指定の機能は File メニューの共有モデル選択 → サーバー既定の順で決まります。
- 接続先は LLM 設定画面の BYO 行か、サーバー既定の接続先（サイト共通の LLM）を使います。翻訳の接続設定（翻訳専用欄）とは独立して選べます。
- エディターでは選択範囲の「Ask AI」やインライン補完も同じ LLM 設定画面の行を利用します。
- 翻訳特化モデル（plamo-3-translate など）は相談用には向きません。汎用チャットモデル（Gemma・plamo 対話版など）が入った行を選んでください。
